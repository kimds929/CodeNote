앞으로 개발 Gate를 설계하기 전에 Baseline을 먼저 확인하라.

Baseline은 현재 작업의 시작 기준 상태이며 최소한 다음을 포함한다.

- Project Root
- Branch
- HEAD
- Working tree
- 직전 공식 PASS 상태 또는 현재 기준 상태

기준 정보가 명확하지 않으면 추정해서 채우지 않는다.

Codex가 확인할 수 있는 정보는 작업 시작 시 먼저 확인하게 한다.

예상 Root와 실제 Root가 다르거나,
예상하지 않은 미커밋 변경이 있거나,
기준 상태가 불명확하면 바로 구현하지 말고 HOLD 여부를 먼저 판단한다.

앞으로 모든 Gate 제안에는 가능하면
"현재 기준 상태" 또는 "Baseline"을 먼저 제시하라.

지금은 실제 개발을 시작하지 말고
Baseline이 왜 필요한지 간단히 설명하라.
