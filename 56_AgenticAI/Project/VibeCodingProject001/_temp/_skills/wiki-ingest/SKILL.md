# 스킬: wiki-ingest

raw의 원본을 읽고, 사용자와 짧게 대화한 뒤, wiki에 지식으로 반영하는 워크플로우. 소스 하나를 넣으면 지식 노트·INDEX·log까지 한 번에 처리된다.

## 입력

- `raw/`의 파일 1개 이상 (문서·회의 메모·데이터·웹 클리핑)

## 절차

### 1단계 — 소스 이해

1. 원본을 읽는다. **raw는 절대 수정하지 않는다** (불변 원본).
2. 소화하기 전에 짧은 요약을 보여준다 — **핵심 내용 3줄 + 다루는 개념**.
3. 한 가지만 묻는다: **"이 자료에서 특히 남기고 싶은 게 있나요?"** — 사용자가 간단히 답하거나 "넘어가줘"라고 하면 그대로 진행한다.

### 2단계 — wiki 반영

4. `wiki/INDEX.md`를 먼저 확인한다 — **중복 생성 방지, 기존 노트가 있으면 새로 만들지 말고 업데이트.**
5. **시간이 지나도 참인 지식만** 뽑아 wiki의 알맞은 카테고리에 지식 노트를 만든다 — 그날의 일정·잡담은 제외 (그건 Meeting 기록의 몫).
6. 노트에는: YAML frontmatter(`type` `title` `description` `tags` `timestamp`) + 사실과 해석 구분 + 출처 `[[원본 위키링크]]`.
7. `wiki/INDEX.md` 갱신 (한 줄, 120자 이내) + `wiki/log.md`에 기록:
   `- [YYYY-MM-DD] wiki-ingest | 원본 파일명 → [[생성·갱신한 노트]]`

## 출력

- wiki 지식 노트 (신규 또는 보강) · INDEX·log 갱신

## 규칙

- 원본에 없는 내용을 지어내지 않는다. 요약은 사실만 — 해석은 구분해서.
- 중요한데 판단이 애매한 것은 "확인 필요"로 표시한다.
