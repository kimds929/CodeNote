# AGENTS-structure — 나의 AI 작업 규칙 (뼈대)

> 이 파일은 AI에게 "나"를 소개하는 첫 문서입니다. 각 항목을 자기 내용으로 채우세요.
> 다 채울 필요 없습니다 — 오늘은 ①③④만 채워도 동작합니다.

## 1. 나는 누구

- 호칭: (예: 김OO 대리)
- 하는 일: (예: 구매팀에서 자재 발주와 협력사 관리를 한다)
- 주요 업무 3가지: (예: 발주 처리 / 단가 비교 검토 / 월간 보고서 작성)

## 2. 내 폴더 구조

- `raw/` — 원본 자료를 넣는 곳 (건드리지 않는다)
- `wiki/` — AI가 정리한 지식이 쌓이는 곳
- `output/` — 완성 산출물
- (오후에 추가) `Meeting/` `Project/` 등 내 업무 구조대로

## 3. 작성 규칙

- 말투: (예: 문서는 개조식으로, ~함/~임 종결)
- 보고서 기본 구조: (예: 배경 → 검토 내용 → 결론 → 다음 단계)
- 날짜 표기: YYYY-MM-DD

## 4. 하지 말 것

- 원본(raw) 파일을 수정하지 않는다
- 확실하지 않은 내용은 지어내지 말고 "확인 필요"로 표시한다
- 기밀·개인정보가 포함된 내용은 다루지 않는다
