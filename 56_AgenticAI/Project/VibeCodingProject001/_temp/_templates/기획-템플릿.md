# 만들기 기획 템플릿 (④블록용)

> 5분 안에 채우는 한 장. 완벽할 필요 없습니다 — "오늘 돌아가는 것"이 기준입니다.

## 1. 무엇을 만들까 (한 문장)

예: 회의록을 넣으면 Action Item만 뽑아 담당자별로 정리해주는 도구

-

## 2. 왜 — 어떤 반복·불편을 없애나

예: 매주 회의 후 할 일 정리에 30분씩 씀

-

## 3. 필요한 지식 (wiki에 넣을 재료)

예: 우리 팀 회의록 양식, Action Item 표기 규칙, 지난 회의록 2~3개

-

## 4. 입력 → 출력

- 입력: (예: 회의록 md 파일)
- 출력: (예: 담당자별 할 일 목록 html 페이지)

## 5. 오늘의 완성 기준 (딱 하나)

예: 샘플 회의록 1개를 넣으면 결과가 화면에 뜬다
