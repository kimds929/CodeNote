앞으로 Codex 또는 내가
현재 Gate와 관계없는 문제를 발견했을 때
다음 원칙을 적용하라.

A. 현재 Gate 완료에 반드시 필요한 문제

- 현재 승인 범위 안에서 최소 수정이 가능한지 판단한다.
- 수정했다면 이유와 변경 범위를 Evidence에 기록한다.

B. 현재 Gate와 직접 관계없는 문제

- 임의로 수정하지 않는다.
- "범위 밖 발견사항"으로 기록한다.
- 필요하면 후속 Gate 후보를 제안한다.

범위 밖 발견사항은 다음 형식으로 간단히 기록한다.

- 발견 내용
- 현재 Gate 영향 여부
- 현재 처리: 수정하지 않음 / 최소 수정
- 후속 Gate 필요 여부

좋아 보이는 개선이라도
현재 Gate의 목적과 직접 관계없다면
자동으로 현재 작업에 포함하지 않는다.

지금은 범위 밖 발견사항을
왜 바로 수정하면 안 되는지 설명하라.
